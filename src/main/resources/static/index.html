YOUR HEALTH COMES FIRST

A note about symptom guidance.

CarePath’s symptom matching is an educational project tool—not a medical device, diagnosis, or treatment plan. Any temporary self-care information is general and not personalized medical advice. Never start, stop, or change medication based on this website. Talk to a licensed clinician or pharmacist for advice tailored to you.

Experiencing severe chest pain, trouble breathing, fainting, signs of stroke, or heavy bleeding? Contact your local emergency service or go to the nearest emergency department now. Do not wait for an online appointment.

ABOUT THE PROJECT

Healthcare guidance,
built with Java OOP.

CarePath is a student-built prototype that connects a patient’s symptom check-in to a possible specialty, doctor availability, and an appointment request. Its Java backend uses JDBC and MySQL for accounts and appointment records; it is a learning project, not a real clinic service.

Suggested project modules

  • Account registration and login
  • Symptom entry and privacy-conscious data handling
  • Recommendation rules and specialty directory
  • Doctor availability and appointment requests
  • Patient and administrator dashboards

Java OOP concepts in the system

Encapsulation

Keep account, doctor, and appointment data behind clear methods.

Inheritance

Share common account behavior across patient and administrator roles.

Abstraction

Separate recommendations and data access behind simple interfaces.

Polymorphism

Support different recommendation strategies behind one shared contract.

Possible classes: User, Patient, Doctor, Symptom, Appointment, and RecommendationService.

QUESTIONS

Good to know

A few important things about this student project.

Does this website diagnose a condition?

No. Symptom matching is an educational demonstration and may be wrong. Only a qualified clinician can diagnose or recommend treatment.

Does the website prescribe medicine?

No. It may show general self-care information, but it does not prescribe a medicine or provide individualized doses. Ask a clinician or pharmacist what is safe for you.

Can I book an appointment here?

You can submit a demo appointment request with a listed doctor. In this student project, it is a simulated workflow and does not contact a real clinic.

How is project data stored?

The Java version saves registered accounts and appointments in MySQL through JDBC. The standalone webpage preview uses this browser only and is for trying the interface; its demo data is not shared with the Java database.

What should I do if symptoms are severe?

For chest pain, difficulty breathing, fainting, signs of stroke, severe bleeding, or another emergency, contact your local emergency service or go to the nearest emergency department now.
